# cpswpg.ca on Astro

```bash
npm install
npm run assets      # downloads all images from the old WordPress site + builds the gallery
cp .env.example .env  # add your form endpoint (Formspree / Web3Forms)
npm run dev
npm run build       # output in dist/
```

- All home page text and shared data: `src/data/site.ts`
- Inner page text: `src/pages/*.astro`
- Gallery: `src/data/gallery.json` (generated by `npm run assets`)
- TODO markers: grep for `TODO` (counters, Best in Winnipeg badge, before/after photos, address).
